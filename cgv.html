Les règles applicables à l’achat de billets sur Prime Football, primeleaguetickets.com.

Dernière mise à jour : 3 octobre 2026

1. Objet

Les conditions générales de vente régissent la vente de billets sportifs sur Prime Football.

2. Éditeur

Service exploité par Prime Football — voir les mentions légales.

3. Billets

Places Premier League / Champions League. Droit d’accès soumis au règlement du stade. Plusieurs billets d’une même commande sont des places côte à côte.

4. Commande

La commande est enregistrée avec ton nom et ton e-mail. Un code du type AB3K-7NP2 est envoyé par e-mail : avec l’adresse de la commande, c’est le seul moyen de retrouver les e-billets.

5. Prix

Euros TTC, frais éventuels affichés avant paiement.

6. Paiement

En ligne. La commande est confirmée après validation.

7. E-billets

Chaque place a un QR code unique. Le scanner ouvre la page de validité du billet (match et date). Tu retrouves tes billets sur Mes billets uniquement avec le code reçu par e-mail.

8. Pas de rétractation

Art. L221-28 : pas de rétractation pour les loisirs à date déterminée.

9. Report / annulation

  • Report : billet valable pour la nouvelle date
  • Annulation : remboursement ou équivalent selon l’organisateur

10. Accès stade

Contrôles de sécurité. Un billet frauduleux peut être invalidé.

11. Revente

Revente non autorisée = risque d’annulation sans remboursement.

12. Responsabilité
